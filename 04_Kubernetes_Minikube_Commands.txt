KUBERNETES / MINIKUBE — WINDOWS CMD OR POWERSHELL

CHECK:
docker version
minikube version
kubectl version --client

START:
minikube start --driver=docker
minikube status
kubectl cluster-info
kubectl get nodes

DEPLOY NGINX:
kubectl create deployment nginx-app --image=nginx:latest
kubectl get deployments
kubectl get pods
kubectl get pods -o wide
kubectl describe deployment nginx-app

EXPOSE:
kubectl expose deployment nginx-app --type=NodePort --port=80
kubectl get services
minikube service nginx-app --url
(Use the URL shown; keep terminal open if Minikube uses a tunnel.)

SCALE:
kubectl scale deployment nginx-app --replicas=3
kubectl get pods
kubectl scale deployment nginx-app --replicas=1

DELETE POD AND AUTOMATIC REGENERATION:
kubectl get pods
kubectl delete pod <ACTUAL_POD_NAME>
kubectl get pods -w
(Deployment creates a replacement pod automatically.)

UPDATE IMAGE / ROLLOUT:
kubectl set image deployment/nginx-app nginx=nginx:stable
kubectl rollout status deployment/nginx-app
kubectl rollout history deployment/nginx-app
kubectl rollout undo deployment/nginx-app

DEBUG:
kubectl get all
kubectl describe pod <ACTUAL_POD_NAME>
kubectl logs <ACTUAL_POD_NAME>
kubectl get events --sort-by=.metadata.creationTimestamp
minikube logs

CLEANUP:
kubectl delete service nginx-app
kubectl delete deployment nginx-app
minikube stop
minikube delete

COMMON ISSUES:
- Minikube cannot start: start Docker Desktop, verify docker info, retry minikube start --driver=docker.
- ImagePullBackOff: check image name/tag and network with kubectl describe pod.
- Pending: kubectl describe pod and inspect resource constraints.
- Do NOT type <ACTUAL_POD_NAME> literally: replace with output from kubectl get pods.
